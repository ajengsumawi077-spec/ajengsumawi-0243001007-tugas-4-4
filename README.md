## Deskripsi Project
Project ini adalah website portofolio personal yang dikembangkan sebagai tugas Ujian Tengah Semester (UTS). Website ini menampilkan profil diri, keahlian teknis, dan informasi kontak. Website dibangun dengan fokus pada tampilan yang responsif, bersih, dan pengalaman pengguna yang nyaman.

1. Pastikan Anda telah menginstal **Node.js** di perangkat Anda.
2. Buka terminal atau Command Prompt di dalam folder project ini.
